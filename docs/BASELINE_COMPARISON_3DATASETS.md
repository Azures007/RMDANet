# 三数据集基线对比（pavia / houston / hyrank）

统一协议：源域 **180 标签/类**，目标域训练零标签，目标 GT 只在最终评估打开一次；
50 epochs（RMDANet 为 50×40 steps）；seed 1237；单卡 RTX 4090。
复现基线使用保幅度 median 归一化；RMDANet 使用逐像元 L2 + 残差 DRSE + 双向融合 + RFTM + RTML。

## 说明（论文脚注）

1. **CACL** 使用作者官方代码（github.com/Ding-Kexin/IEEE_TCSVT_CACL），保留其原始设置
   （patch 5、min-max 归一化、lr 5e-4、batch 36、其网络结构），仅将源域采样改为 180/class、
   训练轮数改为 50，并补充 HyRANK/Houston 数据入口。
2. **DAN / DANN / JAN / MTLDA / UIPCL / PCDM / VCMoE** 为在**完全相同的 UDA 协议**下的复现实现：
   共享轻量 HSI-CNN backbone（3 conv + GAP + FC），仅适配损失不同；使用保幅度 median 归一化。
   其中 MTLDA / VCMoE 无公开官方代码；UIPCL 官方仓库的训练集使用目标域标签（半监督），
   不适用于 UDA 比较；PCDM-UDA 官方实现依赖 Gurobi 求解器（受限 license 无法处理目标域规模）。
3. **RMDANet** 使用逐像元 L2 归一化 + 残差 DRSE + 双向可靠性融合 + RFTM + RTML。
4. 所有方法共享同一数据切分与同一评估代码（OA/AA/Kappa，逐像素混淆矩阵）。

## 结论

- RMDANet 在三个数据集上 OA 均最高：
  Pavia **85.73**（次优 CACL 79.11，+6.62）、
  Houston **79.06**（次优 JAN 75.02，+4.04）、
  HyRANK **58.20**（次优 CACL 55.93，+2.27）。
- 复现基线的绝对数值低于其原文（backbone 与训练预算不同），论文中已注明，不与原文数字直接比较。
- HyRANK 上 VCMoE（复现）AA 68.71 高于 RMDANet 60.36，但 OA 低 3.47；该数据集类别极不均衡
  （类 10 在所有方法中均为 0%），已在正文讨论。
