# 模型对比：旧基线 85.55 vs 当前 92.13 vs 官方 MSDA 93.93

> 数据集：PaviaU → PaviaC，180 标签/类，单 seed 1237，最后一轮评估。
> - **旧基线 85.55**：`main` 分支 v3.0（tag `v3.0`，commit `c0783a7`），文件 `core/model.py` + `core/trainer.py`
> - **当前 92.13**：`msda-recipe` 分支（commit `44b1584` 前一轮，`e38e1a5` 修复版），文件 `core/trainer_msda.py` + `core/data.py` + `datasets/*/config_msda.yaml`
> - **官方 MSDA 93.93**：`MSDA_DIR=/root/autodl-tmp/project`（Li-ZK/MSDA-2024），单 seed 1315 复现

---

## 一、整体结论

| 项目 | 旧基线 85.55 | 当前 92.13 | 官方 MSDA 93.93 |
|---|---|---|---|
| 方法归属 | 我们自己设计 | **官方 MSDA 组件 + 我们的可靠性门控 + 我们的数据管线** | MSDA 原版 |
| 与旧基线关系 | — | 无任何共享模块（只共享训练框架/评估脚本） | — |
| 是否含我们的创新 | 是（PRAT/记忆库/多度量对齐） | 是（可靠性门控伪标签，+1.55 于基座） | 否 |
| Pavia OA | 85.55 | **92.13** | 93.93 |
| Pavia AA | 82.74 | 90.60 | 92.50 |
| Kappa | 0.8258 | 0.9052 | 0.9268 |

## 三、网络结构（模块级）

| 模块 | 旧基线 85.55 | 当前 92.13 | 官方 MSDA 93.93 |
|---|---|---|---|
| 骨干 | 自研 `LocalSpectralSpatialEncoder`（3D 局部光谱-空间，64 通道） | **官方 `SSSE_test`**（3D 光谱支路 24→128 + SpectralSE；3D 空间支路 24 + SpatialSE；融合 152） | 官方 `SSSE_test`（同） |
| 2D 加工 | `semantic2d`：3×ResBlock2D（64→96→128） | SSSE 内部 3D 残差块（152→152）+ 注意力 | 同 |
| 多尺度 | `micro-ASPP`（3 尺度选择，128→32） | 无 | 无 |
| 池化 | `CenterGuidedPooling`（中心 3×3 引导，注意力温度 0.12） | 官方 `AvgPool3d` | 同 |
| 光谱分支 | `CenterSpectralShapeEncoder`（bands→160） | 无（SSSE 内含光谱注意力） | 无 |
| 融合 | `SpectralReliabilityFusion`（160，可靠性门控 gate 0.12） | 无（两路 concat 152） | 无 |
| 特征维度 | 160（MLP 128→256→160） | 152 | 152 |
| 分类头 | **单** `CosineClassifier`（160→C，scale 12） | **双** `ResClassifier`（152→76→C，BN+ReLU+Dropout 0.5，`weights_init`） | 同（双头） |
| 频率域迁移 | **PRAT**（相位可靠性残差幅度迁移，强度 0.2） | 无 | 无 |
| 伪标签记忆库 | **ReliabilityPrototypeMemory**（多子原型、空间邻居可靠性、原型否决、cleanlab） | 无 | 无 |
| EMA 教师 | 学生 EMA（decay 0.996），用于一致性损失 | **官方 `EMATeacher(G,F1)`**（alpha 0.9，prob 加权） | 同 |
| 掩码自蒸馏 | 无 | **官方 `Masking_new`×2**（块 32、比例 0.7、颜色抖动 0.2、谱/空间掩码、谱块 9、空间块 4） | 同 |
| 双分类器对抗 | 无 | **有**（L1 差异，Step B/C，num_k=3） | 同 |
| 类崩溃守卫 | 有开关（关闭） | 无（用类配额替代） | 无 |
| **可靠性门控伪标签（我们的增量）** | 记忆库+多票否决（旧协议下开发） | **有**：教师概率 ≥0.95、每 batch 每类上限 16、概率加权伪标签 CE 权重 0.05 | **无** |

## 八、与文献方法（MSDA / TAPDA / SCLUDA）的关系

| 方法 | 骨干 | 训练范式 | 我们的当前模型与之关系 |
|---|---|---|---|
| MSDA-2024（TGRS） | SSSE | 掩码自蒸馏 MIC + MCC + 双分类器对抗 + EMA 教师 | **完全一致**（组件级复现）+ 我们的可靠性门控 |
| TAPDA-2026（JSTARS） | SSSE | MSDA 基础上加源原型对比蒸馏 + 目标类 top-k 对比 | **未实现**（我们缺两块对比学习） |
| SCLUDA | 3D CNN | 对比 + 目标域伪标签，按目标测试集选 epoch（有泄漏） | 未采用 |

> 官方 MSDA 论文 Pavia 报 92.44，我们复现 93.93（单 seed，可能因我们的 GT/数据版本略优）。
> TAPDA 的 Pavia 数字尚未核实；若要对比需要移植其对比学习模块。
