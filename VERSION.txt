RMDANet v7.2-advisor
=====================
Built: 2026-11-16
Rollback point: git tag pre-advisor-20261116 (commit d26c1f8)

Changes in v7.2:
  - HyRANK canonical config: patch_size=5, pool_center_size=3 (verified 3 seeds, +2.53).
  - Full training entry unified: HyRANK now uses bidirectional spectral fusion
    (same as Pavia/Houston); the old label-free fusion-off rule is removed.
  - MERGE_CONSISTENCY env removed (it had no real merge implementation).
  - LOSS_PROFILE=compact (optional): folds external Scale Pair / Center Pair
    into the composite style-consistency loss (top-level terms 14 -> 12).
    Default remains "full"; equivalence must be verified per seed first.
  - scripts/verify_run_config.py: checks run_config.json against canonical
    per-dataset patch/centre/fusion and reports mismatches.
  - Terminology: CCA -> CCC (Class-conditional Contrastive Alignment);
    LMMD -> reliable class-mean alignment (linear-kernel MMD form).
  - Hard Contrastive (STAGE3_HARD) stays disabled and is ablation-only.

Prior package: RMDANet clean-v7 (2026-11-12, base commit 8151039).
